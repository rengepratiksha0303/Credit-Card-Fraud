# Credit Card Fraud Detection

This project detects fraudulent credit card transactions using Machine Learning models:

- KNN
- ANN
- CNN

## Dataset

credit_card_fraud_synthetic.csv

Features:

- Time
- V1
- V2
- V3
- V4
- V5
- Amount

Target:

- Class (0 = Genuine, 1 = Fraud)

## Installation

```bash
pip install -r requirements.txt
```

## Run Application

```bash
streamlit run app.py
```

## Model Files

- knn_model.pkl
- scaler.pkl
- ann_model.h5
- cnn_model.h5
